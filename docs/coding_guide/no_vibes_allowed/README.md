# No Vibes Allowed: Solving Hard Problems in Complex Codebases

- **Talk:** No Vibes Allowed: Solving Hard Problems in Complex Codebases
- **Speaker:** Dex Horthy (@dexhorthy), Founder & CEO, HumanLayer
- **Event:** AI Engineer Code Summit (AI Engineer Code 2025), published on the AI Engineer YouTube channel
- **Date:** 2 December 2025
- **Length:** 20:31
- **Video:** <https://www.youtube.com/watch?v=rmvDxxNubIg>
- **Talk page:** <https://ai.engineer/talks/rmvDxxNubIg-context-engineering-for-complex-codebases>
- **Blog:** <https://www.humanlayer.com/blog/advanced-context-engineering>

Dex Horthy argues that today’s coding models already work in large, established (“brownfield”) codebases if you treat the context window as a scarce engineering resource. The naive loop of chatting, correcting, and resteering fills the window with junk and pushes the model into what he calls the dumb zone. The alternative is frequent intentional compaction — research, then plan, then implement — with humans reviewing the research and the plan, not only the final diff.
