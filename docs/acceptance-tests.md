# TINNOX CMS acceptance tests (first release)

Date: 2026-11-03. Status: PROPOSED. These tests define "done" for the first release described in `docs/tinnox-mvp-spec.md`. They are written against TINNOX CMS behaviour, not Yodeck's; where a Yodeck behaviour informed a test it is noted as a reference only. Revised on 2026-11-03 with TINNOX's answers to Q1 to Q12 and the round-2 research (`research/round2/R99-critic.md` section 2.7). Release 1 is Australia only (TINNOX answer Q6). Release 1 has two controller vendors, Huidu (TINNOX answer Q2) and NovaStar (named on the TINNOX site, `research/round2/R5-tinnox-site.md`).

## 0. Conventions

- **Validation level**: `SIM` = can pass in a desktop browser or the player simulator (Chromium on a workstation, or a container); `HW` = must pass on the real pilot hardware (player plus display or LED controller). A test marked `SIM+HW` must pass at both levels; the HW run is the gate.
- **SIM for the Huidu route** means a mock card server that implements the official Huidu HTTP API on port 30080: signed requests, the one-time key write, `getDeviceProperty`, `setDeviceProperty`, `getDeviceStatus`, scheduled tasks, program `replace` and `getAll`, and the screenshot endpoint (VERIFIED_FULL_PAGE, official API document revision 2026-06-16, `research/round2/R1-huidu-integration.md` F4). HW for the Huidu route means the lab Huidu "D" card.
- **Test fixtures**:
  - A dedicated test customer ("TEST Customer") and a second customer for isolation tests.
  - Test sites in Australia/Sydney, Australia/Brisbane and Australia/Perth.
  - Canvases: one portrait kiosk (1080×1920); one custom LED canvas (for example 640×1344); and two TINNOX package canvases, PrecisionPro S1 1376×774 and PrecisionLuma S1 768×448 (VERIFIED_FULL_PAGE, `research/round2/R5-tinnox-site.md` verification #9 and #10). The 768×448 canvas is not 16:9 (ratio 1.714). The 1376×774 canvas is 16:9 but not a standard video size. PrecisionPro S2 to S4 and PrecisionLuma S2, S4 and S5 are not 16:9 either; the PrecisionMicro sizes and PrecisionLuma S3 are.
  - Synthetic media only: generated colour bars, slates with embedded timestamps, a 10-second H.264 clip, the same clip in HEVC, a deliberately corrupt file, and a 3-page PDF.
  - Players: one CM5 player in an industrial box rated −25 to +60 °C (EDATEC ED-IPC3630 class, OFFICIALLY DOCUMENTED datasheet, `research/round2/R4-player-hardware-recommendation.md`), and one RK3588 Android 14 box with the TINNOX app as device owner.
  - Huidu "D" engineering cards in the lab (device ID contains "D", for example the official sample C16L-D00-A000F), reached through an on-site agent, plus the mock card server above. One card is the minimum; HUI-03 and HUI-08 are easier with two, one of them behind a 4G router with VPN. Only "D" cards support the HTTP API (OFFICIALLY DOCUMENTED, R1). A key can be written to a card only once (OFFICIALLY DOCUMENTED, R1 verification #6), so key tests use a dedicated lab key and lab card.
  - Plans Essential, Professional and Managed, and displays in each licence state (`demo`, `included`, `active`, `grace`, `suspended`, `expired`) (PROPOSED, `research/round2/R6-commercial-model.md`).
  - Two TINNOX operator accounts and one TINNOX manager account, each a named person with MFA, for the support-access tests.
  - No customer content, real credentials or real vendor keys are used in tests. Test keys and secrets live in the test environment's secrets vault only.
- **State names** used in expectations come from the spec: media `uploaded → processing → ready | failed`; publication `draft → published`; per-display delivery on the TINNOX player route `pending → downloading → downloaded → playing | error`; on the Huidu program push route `pending → sent → card-downloaded → playing (sampled) | error` (spec section 12). Playback evidence is `logged` (TINNOX player) or `sampled` (Huidu route).
- Each test lists: preconditions, steps, expected result, evidence to attach (screenshot, log excerpt, telemetry record).
- Timing numbers in expectations are **release targets** to be confirmed during the pilot, not measured facts.
