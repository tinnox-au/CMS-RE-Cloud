# Web Interface Guidelines

Read `command.md` in this folder before a frontend review. It is the pinned Vercel Web Interface Guidelines. Use that local file, including when offline.

Check the changed UI files in the portal, the player, and `packages/app-render` against those rules.

Report each finding as `path:line`, with a severity from the scale in `AGENTS.md`: Critical, High, Medium, Low, or Observation.
